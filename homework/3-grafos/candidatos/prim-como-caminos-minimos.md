# Caminos de costo mínimo a partir del MST de Prim

**(20%)**

Determine si el siguiente procedimiento para calcular los caminos de costo mínimo desde un vértice fuente a todos los demás vértices en un grafo no dirigido es correcto. En caso de no serlo, dé un contraejemplo.

1. Ejecutar el algoritmo de Prim para encontrar un árbol de recubrimiento mínimo.
2. Construir el camino desde la fuente hasta cada posible destino utilizando las aristas del árbol de recubrimiento mínimo.
