\section{Comandos de símbolos}
A continuación se presenta una tabla con los comandos para algunos símbolos relevantes; estos deben ser usados en un ambiente matemático:
\begin{itemize}
  \item Entre los símbolos \verb|\(| y \verb|\)| para escribir matemática al interior de un párrafo.
  \item Entre los símbolos \verb|\[| y \verb|\]| o en el ambiente \texttt{equation} para escribir matemática en un bloque aislado.
\end{itemize}
