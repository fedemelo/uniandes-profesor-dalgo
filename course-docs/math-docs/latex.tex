\section{\LaTeX{}}

Una alternativa para despojarse de preocupaciones relacionadas con convenciones de escritura matemática es utilizar \LaTeX{}, que aplica correctamente la inmensa mayoría de convenciones de forma automática.

Para aprender a usarlo, remítase al sitio oficial del proyecto \cite{latexproject}, a \cite{oetiker2021lshort}, o al curso interactivo de Overleaf para principiantes \cite{overleaf2024novice} (quizás la mejor opción para empezar).
